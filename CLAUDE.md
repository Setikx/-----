# Правила подготовки баз насосов для PumpQH

* Только **заводские кривые**: таблицы Q–H или графики из каталога/сайта изготовителя (`Source.Quality = CatalogTable`).
  Никогда не строить и не аппроксимировать кривую по номинальной точке. Если у модели нет опубликованной кривой — не включать её,
  занести в `data/catalogs/excluded.json` и сообщить пользователю.
* Брать **самые свежие** каталоги изготовителя; издание и дату указывать в `Source.Document`.
* Характеристики — для сети **50 Гц** (РФ). Данные 60 Гц не использовать, если у изготовителя есть 50 Гц.
* Формат записей — `PumpRecord` (см. `data/pumps.sample.json`); ноль = «неизвестно». Скрипты — `tools/catalogs/`.
