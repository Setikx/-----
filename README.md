# PumpQH — модель насоса и пример базы

Фрагмент программы PumpQH (график Q–H, подбор насосов для КНС, гидроудар): класс записи базы насосов и пример файла базы.

## Состав

| Файл | Что это |
|---|---|
| `src/PumpQH.Core/Model/PumpRecord.cs` | Запись базы насосов (`PumpRecord`) и её части: паспортные кривые (`PumpCurve`, `CurvePoint`), источник данных (`SourceInfo`), тип рабочего колеса (`ImpellerType`), происхождение кривой (`CurveQuality`). Зависит только от `System.Text.Json`. |
| `data/pumps.sample.json` | Пример файла базы — три записи в том же формате, что и полная база программы (`data/pumps.json`, массив записей). |

## Формат записи

* Единицы: подача Q — м³/ч, напор H — м, мощность P — кВт, КПД — %, NPSHr — м, размеры — мм.
* `Curve` — кривые при номинальной частоте вращения и полном колесе, списки точек `{ "Q": …, "V": … }`:
  `QH` (напор, обязательна), `QP` (мощность на валу P2), `QEta` (КПД насоса), `QNpsh` (NPSHr); пустой список — нет в каталоге.
* `Source.Quality` — насколько можно доверять кривой:
  `CatalogTable` — точки из таблицы или графика каталога изготовителя;
  `CatalogNominal` — только номинальная точка (или Qmax / Hmax / Qopt / Hopt), форма кривой аппроксимирована;
  `User` — введено пользователем.
* `RangeQmin` / `RangeQmax` — рабочая область по паспорту; 0 — считается по кривой (ANSI/HI 9.6.3).
* `TrimMin`, `SpeedMin` — допустимая обточка колеса и наименьшая частота при ЧРП, доли номинала.
* Ноль в числовом поле означает «неизвестно».

## Записи в примере

| Насос | Происхождение кривой |
|---|---|
| Grundfos SEG.40.09.2.50B | `CatalogTable`: Q–H, P2 и КПД |
| Pedrollo VXC 15/50 | `CatalogTable`: только Q–H |
| Wilo Rexa CUT GE03.20 | `CatalogNominal`: номинальные точки, форма кривой аппроксимирована |

Характеристики взяты из открытых каталогов изготовителей (ссылка на документ — в `Source` каждой записи) и служат примером формата, а не справочником для проектирования: для проекта сверяйте данные с актуальным каталогом.

## Базы из каталогов изготовителей (`data/catalogs/`)

Объединённый файл — `data/pumps.catalogs.json` (**2110 моделей**); по брендам — `data/catalogs/<бренд>.json`;

Скрипты извлечения — `tools/catalogs/` (Python: PyMuPDF, RapidOCR, OpenCV).

**Точность и ограничения.**
* **Правило базы: только заводские кривые.** Все записи — `Source.Quality = CatalogTable`: точки из таблицы или оцифровка графика каталога/сайта изготовителя. Кривые, построенные по номинальной точке, в базу **не включаются**; если у изготовителя нет опубликованных кривых — модель исключается и указывается в `excluded.json`. Способ получения указан в `Notes` каждой записи.
* Исключены по этому правилу: Tsunami — 270 моделей, у которых на сайте вместо кривой схема из 3 точек (вся серия AFP, часть AS-WQ и WQ), и 87 карточек без графика; Fancy WQS (82 модели, в каталоге только номинал + Hmax/Qmax); Aquastrong SEP100CA.
* Оцифрованные кривые проверены по номинальным/табличным точкам каталога; расхождение указано в `Notes`. Где каталог сам себе противоречит (таблица ≠ график), это отмечено словом «ВНИМАНИЕ».
* `QP` там, где в каталоге дана P1, пересчитана в P2 по номинальному КПД двигателя — приближённо (оговорено в `Notes`). `NominalEta` у Caprari — максимальный КПД гидравлики по графику.
* Ноль в числовом поле — «неизвестно» (как в основном формате).
* Не вошли: Vandjord VSL 2-го поколения и часть крупных моделей (кривые перепутаны при трассировке), MASDAF Enduro Lite и PS/PSH, Caprari K-Kompact (текст каталога в нестандартной кодировке), Purity PZW и растровые графики Purity WQ (стр. 13–14), Aikon SSC — 7 графиков. Список отбракованных при проверке — `excluded.json`.
* Для проекта сверяйте выбранную модель с актуальным каталогом или программой подбора изготовителя.
